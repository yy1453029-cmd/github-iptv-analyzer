SYSTEM NOTES

Transparent by design.

GitHub IPTV Analyzer queries only official public GitHub API endpoints and public repository URLs. Parsing is done locally in the browser. No credentials are requested, no password checks are performed, no private content is accessed, and no server or proxy testing is attempted.
